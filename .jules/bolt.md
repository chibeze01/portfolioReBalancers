## 2025-04-06 - N+1 Bottleneck in Recommendation Service
**Learning:** Found an N+1 performance bottleneck in `recommendation_service.py` where `_analyze_portfolio_sectors` fetched stock sector info sequentially for every holding in a loop.
**Action:** Implemented a new concurrent `get_stock_info_batch` method in `yahoo_provider.py` using `ThreadPoolExecutor` (mirroring the existing `get_prices_batch` pattern) and refactored the recommendation service to batch-fetch stock info before processing. Always check loops that make external API calls for batching opportunities.
