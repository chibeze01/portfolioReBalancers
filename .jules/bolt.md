## 2025-02-28 - Optimized Sequential API lookups to ThreadPool execution
**Learning:** Found N+1 sequential price lookups in domain logic, heavily slowing down analytics computations. Specifically `efficient_frontier_service.py` fetched `get_historical_prices` continuously inside loops causing high overall request time blockages.
**Action:** Use ThreadPoolExecutor to batch fetch data. Extract sequential execution into a single concurrent batch logic `get_historical_prices_batch` to avoid performance bottlenecks, carefully preserving any local logic fallback to `stub_provider` by keeping original default return maps or caching.
